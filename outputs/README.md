# Generated outputs

This folder contains the destinations for artifacts created by `python run_analysis.py`. The real UCI dataset could not be downloaded in the build environment because outbound DNS/network access was unavailable, so no real-data charts, RFM tables, or segment claims are included here. Place `Online Retail.xlsx` at `data/online_retail.xlsx` and run the pipeline to populate the folders. The integration run used a temporary test fixture outside this project and its outputs were not copied into this submission.
